# fase 2 — buscar

dos caminos que se alimentan entre sí:

1. `familysearch/` → millones de libros parroquiales microfilmados, gratis. **a mano.**
2. `parroquias/` → lo que no está en línea (que es mucho, sobre todo después de ~1930–1960 y en parroquias pequeñas).

orden recomendado para cada persona:
1. ¿tengo nombre + lugar + rango de años? → si no, vuelve a fase1
2. búsqueda indexada en FamilySearch (rápida)
3. si no sale: navegar las imágenes del libro de esa parroquia (lento, pero ahí está lo que el índice no tiene)
4. si no existe en línea: carta (fase3)
