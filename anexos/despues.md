# ¿y después?

- **ADN**: un test autosómico (Ancestry, MyHeritage, FamilyTreeDNA, 23andMe) puede confirmar ramas y romper muros, pero solo sirve si ya tienes un árbol documentado para comparar. no te dice "eres 30% de tal pueblo" con precisión.
- **compartir**: si subes tu árbol a sitios públicos, deja privadas a las personas vivas.
- **visualizar**: pídele al LLM un GEDCOM, un diagrama Mermaid o una página HTML a partir de tu `personas.json`.
- **escribir la historia**: el prompt "resumen para la familia" en `_sistema/prompts_extra.md`.
