# cómo citar una fuente

formato simple (que el LLM entiende y tú también):

```
[tipo] de [persona], [fecha], [parroquia/oficina, lugar], libro [n], folio [n], partida [n].
Visto en: [FamilySearch ark:/... imagen n / foto propia / certificado recibido de ... el AAAA-MM-DD].
```

ejemplo inventado:
```
Bautismo de Juana Gómez Ruiz, 12 mar 1891, Parroquia San José, <municipio>, libro 7, folio 45v, partida 112.
Visto en: FamilySearch, imagen 233 de la película 0000000.
```

- "índice de FamilySearch" sin ver la imagen = cita más débil. anótalo así.
- "árbol familiar de FamilySearch / MyHeritage / Geni" = NO es fuente, es pista.
- guarda la foto del documento con un nombre claro: `AAAA_tipo_Apellido_Nombre.jpg`.
