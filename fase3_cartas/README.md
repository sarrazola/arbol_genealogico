# fase 3 — cartas

consejos que funcionan:
- **corto y específico.** una parroquia recibe muchos correos. di nombre, padres si los sabes, fecha aproximada y tipo de partida.
- **una persona por párrafo**, máximo 3–4 personas por carta.
- ofrece pagar el costo del certificado/donación y pregunta cómo.
- pide **copia o foto de la partida completa con notas marginales** (no solo un "certificado" resumido, que a veces omite los abuelos).
- si es para investigación (no trámite), dilo: a veces basta con una foto del libro.
- archivos y notarías pueden pedir carta firmada + copia de tu documento de identidad.
- si no responden en ~7 días: `plantillas/seguimiento.md`. luego llama o WhatsApp.

el LLM las redacta con: `CARTA para <persona>` y los datos que tengas.
